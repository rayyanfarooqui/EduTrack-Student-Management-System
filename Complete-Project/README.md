# EduTrack – Student Management and rank System

## Project Overview
EduTrack is a C++-based Student Management System developed as part of our Data Structures and Algorithms (DSA) and Object-Oriented Programming (OOPS) project. It provides basic student record management, searching, sorting, ranking, academic reporting, and file-handling functionality.

## Features
- Student record management
- Searching and sorting student records
- Student ranking
- Stack and queue operations
- Undo functionality
- Academic reports
- File handling for student data

## Technologies Used
- C++
- Data Structures and Algorithms
- Object-Oriented Programming
- File Handling

## Project Structure
- `include/` – Header files
- `src/` – C++ source files
- `.gitignore` – Files and folders excluded from Git tracking

## How to Run
1. Download or clone the repository.
2. Open the project in a C++ IDE such as Code::Blocks.
3. Add the source files from `src/` and header files from `include/` to the project.
4. Build and run the program.
